# Grinding Cost per Part & G-Ratio Calculator

A lightweight preview of the **Grinding Cost per Part Calculator** from
[SinoGrind](https://sinogrind.com).

**Live calculator:** https://sinogrind.com/tools/grinding-cost-per-part-calculator

## What it does

The full tool calculates abrasive, dressing, machine and scrap cost per part
from wheel price, wheel life, dressing cost, cycle time and machine rate. It
also reports G-ratio (material removed ÷ wheel wear) so wheel life and wheel
price can be compared on the same basis.

## Inputs

- Wheel price
- Wheel life (parts per wheel)
- Dressing cost and parts per dress
- Cycle time
- Machine hourly rate
- Scrap or rework rate
